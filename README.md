💰 Budget Management System

A Java-based desktop application designed to help users manage their personal finances, track income and expenses, organize budgets, and analyze their spending habits.

📌 About the Project

Budget Management is a personal finance management application developed using Java and object-oriented programming principles.

The project aims to provide a structured way to manage financial transactions and monitor personal budgets through a graphical user interface.

✨ Current Features

* User Authentication: User registration and login.
* Income Management: Record and manage income transactions.
* Expense Tracking: Add and manage expenses.
* Budget Management: Organize and monitor budgets.
* Category Analysis: Analyze expenses by category.
* Debt Management: Manage financial debts.

🚀 Planned Features

The following features are planned for future versions:

* Financial Notifications: Notify users about relevant financial activities and updates.
* Investment Scenarios: Add functionality for modeling and evaluating investment scenarios.

🛠️ Technologies Used

* Java — Core application development
* Swing — Graphical user interface
* JDBC — Database connectivity
* SQL Database — Data storage
* Git & GitHub — Version control and project hosting
* IntelliJ IDEA — Development environment

⚙️ Setup and Installation

1. Clone the repository:

git clone https://github.com/sarebetul/BudgetManagement.git

2. Open the project in IntelliJ IDEA or another Java IDE.
3. Make sure a compatible Java Development Kit (JDK) is installed.
4. Configure your local database connection settings in db.properties according to your database setup.
5. Ensure the required database and tables are created.
6. Run Main.java to start the application.

Note: Database configuration is stored locally and is not included in the repository. You must configure your own database connection before running the application.
